# LifeSkill

LifeSkill 是一款原生 Android 技能树应用。按学习方向组织技能树和技能点，用地图查看前置关系及点亮进度。可以手动整理技能库，也可以请 AI 生成结构或在单个技能点内进行文字学习。

## 安装与使用

1. 安装 `release/LifeSkill-0.13.2-release.apk`。支持 Android 8.0（API 26）及以上。
2. 首页主卡可开始规划或继续学习。学完当前技能后，首页推荐同一棵树里已解锁的下一项，整棵树完成后可查看地图。学习方向卡底部左侧显示已学会数和总数，右侧用分段刻度表示进度，空方向可直接创建技能树。技能地图纵向滚动，每行最多两个节点，每个节点最多新增两条后续分支。圆形徽章用渐变、小勾、浅色环和锁区分点亮、下一步与未解锁状态。
3. 从悬浮底栏切换「学习」和「我的」。「我的」可查看学习总览、浏览全部证书缩略图，并选择 12 款插画头像或相册照片。右上角「设置」可选浅色、深色或自动跟随系统。使用 AI 前，在「模型设置」选择 DeepSeek 或 MiniMax 并填入对应的 API Key。也可选「自定义」，填写 OpenAI 兼容服务的 HTTPS Base URL、模型名和 Key。「测试连接」验证当前表单，「保存」将其设为当前模型。
4. 在首页或方向页的 AI 对话中描述学习目标。主题明确时会直接弹出生成选项。选择当前掌握程度和课程数量，再点「确认生成」。每次生成一棵树，每棵最多 33 节。新树从唯一的第一级技能点开始，其余技能点都通过前置关系连接到这个起点。草稿生成后会自动弹出「选择学习方向」，选好方向后点「确认添加」。取消后可点草稿消息重新选择。从技能树内使用「AI 追加」会新增到当前树。生成的技能树和技能点都会按内容自动分配图标。结果消息可跳转到对应项目。右上角更多菜单可以清空当前会话，二次确认后会删除聊天记录和未添加的草稿，保留已添加的内容。
5. 点圆形节点查看完整名称、技能说明和前置技能。新增或编辑前置时，只能选择紧邻上一逻辑层的技能。点亮全部前置技能后可开始学习，通过 AI 的掌握检验后点亮当前技能。旧版点亮记录会保留。
6. AI 老师的最新回复没有选项时，可点下方的「好的，继续」接着学。本轮讲解满 5 次后，可点「感觉已经会了，来考试吧」主动检验。AI 也可以提前邀请检验。选择题直接点选项作答，答错后可在提示下重新选择。讲解支持 Markdown、表格、简易流程图和可横向滑动的字符示意图。
7. 在 AI 老师页右上角选择「重新学习」。确认后会清空此技能的旧对话，保留点亮进度。可填写本次要求，AI 会按当前技能说明重新讲解。
8. 点亮一棵树的全部课程后，从地图末尾进入「验收考试」。AI 根据已学课程出 10 道题，包含 4 道单选、3 道多选和 3 道填空。交卷后显示本次分数，可查看历次错题。60 分通过，最高分显示在地图，达到 100 分前可以重考。通过后可上滑拆开信封，证书保存当时的昵称和头像。同一棵树只收藏一张。可从成绩页或「我的」证书展柜查看，删除技能树也会保留已收藏的证书。在展柜打开证书后可隐藏它，之后从「已隐藏」恢复展示。
9. 通过验收并返回地图时，页面会滚动到地图末端，通过蓄力、能量扩散和分离动画显示「自以为是检测」和「费曼复习」。两个挑战使用独立的暗色隐藏徽章，依次表达发现自我认知盲点和递归讲解的思考方式。前者用三道题找出理解漏洞，后者反复练习把概念讲给 10 岁的孩子听。挑战成功后点亮带金色装饰的同一套徽章。

技能库、学习进度、聊天记录、个人资料和证书保存在应用本地。AI 对话将当前任务所需的内容发送给所选模型服务，使用该服务商账户的额度。卸载或清除应用数据会删除本地记录。

## 本地构建

使用 Android Studio 打开仓库，安装 Android SDK Platform 37、Build Tools 36.0.0，并选用 Studio 内置 JDK。命令行在已配置 `ANDROID_HOME` 和 `JAVA_HOME` 的环境中运行。

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

交付包使用 `./gradlew :app:assembleRelease` 构建，用与上一版相同的本机签名证书签名后放入 `release/LifeSkill-<版本>-release.apk`，以便覆盖安装。

连接设备或启动模拟器后，可运行端到端测试。测试使用可控 AI 响应，无需 API Key。

```sh
./gradlew :app:connectedDebugAndroidTest
```

## 项目结构

- `model` 定义技能层级、依赖图和掌握检查规则。
- `data` 负责 Room、事务、加密与仓库。
- `ai` 负责模型接入和结构化回复校验。
- `ui` 包含 Compose 页面和 ViewModel。

持久化和 AI 写入决策见 [MVP 技术设计](docs/mvp.md)。
