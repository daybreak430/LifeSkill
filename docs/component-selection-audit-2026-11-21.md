# 教学组件主题选择实测

## 测试范围

2026-11-21 使用钥匙串中的 LifeSkill DeepSeek 凭据调用 `deepseek-flash`，不再使用本地千问模型。请求使用当前 `TeachingBlockProtocol.instructions`，让模型基于课程主题、课时名称和学习目标开始第一小段教学。场景覆盖：

| 主题 | 课时 | 目标重点 |
| --- | --- | --- |
| 历史 | 秦的统一与灭亡 | 时间顺序、长期原因与直接触发 |
| 数据分析 | 用月度销售数据判断趋势 | 读图、趋势与单月波动 |
| 操作流程 | 手冲咖啡的稳定冲泡 | 顺序、判断点、参数影响 |
| 语言学习 | 现在完成时与一般过去时 | 概念辨析与语境选择 |
| 生物 | 植物细胞的结构与功能 | 部位、功能与易混结构 |

五个返回都成功解析为 JSON，没有格式错误。

## 首轮结果与误用

| 主题 | 实际组件 | 判断 |
| --- | --- | --- |
| 历史 | quiz、timeline | 时间轴合适；首次讲解先放测验偏早 |
| 数据分析 | chart、compare、quiz | 三个组件过密，图表和对比已经承担讲解，再加测验压成展示墙 |
| 操作流程 | flow、sort | 流程图和排序重复表达同一顺序，没有增加新的认知动作 |
| 语言学习 | compare、quiz | 对比合适；测验可以接受，但对首次讲解略重 |
| 生物 | flip、quiz | 没有使用唯一匹配的植物细胞热点图，组件选择不合适 |

据此收紧了规则：每次最多两个组件；只有用户明确要求组合时才允许三个；一次只能有一个主组件；禁止同一顺序同时使用 flow 和 sort；植物细胞目标优先使用 hotspot；练习组件留到讲解完成或学生需要尝试时。

## 收紧提示词后的复测

| 主题 | 复测组件 | 结果 |
| --- | --- | --- |
| 历史 | timeline，6 个事件 | 符合主题 |
| 数据分析 | line chart，6 个连续月数据，轴为“月份 / 销售额（万元）” | 符合主题 |
| 操作流程 | flow，含闷蒸判断与回流 | 符合主题且无重复排序 |
| 语言学习 | compare，紫青配色 | 符合主题 |
| 生物 | hotspot，`plant_cell`，5 个热点 | 符合主题 |

复测中五个主题均选择了一个主组件，没有再出现重复表达、组件堆叠或植物细胞热点缺失。

## 边界

本轮是 5 个针对性样本，验证了主题提示能够明显约束 DeepSeek 的组件选择，不代表所有模型和所有主题都已覆盖。热点当前仍只支持植物细胞固定图，其他空间主题不能使用。
