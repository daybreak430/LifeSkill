# 动效语言

本页规定全应用「状态变化」的表达方式。新增或修改动效时按这里取值，不在调用处自定时长与曲线。全部令牌集中在 [Motion.kt](../app/src/main/java/com/lifeskill/app/ui/Motion.kt)。

## 判断标准

动效的任务是解释发生了什么，而不是装饰。审查时按「状态变化」找，不按部件找：出现、消失、移动、尺寸变化、换内容、换图标、数值跳动、按下、加载、完成、出错，都要能回答三个问题。

1. 东西从哪来、到哪去，和什么有关？
2. 是同一件东西更新了，还是换成另一件？
3. 用户此刻最想看到的是结果，还是过程？

第三题的答案是「结果」时就不要动画。用户反复做的操作（按下、切换标签、翻页）一律走最短档，宁可少动。

## 令牌

| 令牌 | 时长 | 用途 |
| --- | --- | --- |
| `Motion.Instant` | 90ms | 按下反馈、颜色微调 |
| `Motion.Quick` | 150ms | 小元件出现消失、文字换值、标签选中 |
| `Motion.Base` | 220ms | 页面转场、卡片换内容、区块展开（默认档） |
| `Motion.Gentle` | 320ms | 大块内容替换、表单展开、进度条补齐 |
| `Motion.Hero` | 520ms | 用户主动触发的一次性主场动画（翻卡、庆祝） |

曲线只有三条：

- `Motion.Standard`：标准曲线，起步就给速度、收尾停稳，用于位移与换内容。
- `Motion.Decelerate`：进入画面，到达快、停得软（`motionIn`）。
- `Motion.Accelerate`：离开画面，比进入更短，不拖住下一步（`motionOut`）。

组合工具：

- `contentSwap()`：同一位置换内容。旧内容快速淡出，新内容延后 60ms 淡入，避免两段文字同时可见的重影；尺寸用同一时长过渡，卡片不跳高矮。只能写在 `AnimatedContent` 的 `transitionSpec` 里。
- `expandFade()` / `shrinkFade()`：区块在布局里展开和收起，高度与透明度一起变。父容器没有尺寸动画时用它。
- `appearFade()` / `disappearFade()`：只淡入淡出。父容器已经用 `animateContentSize` 管高度时用它，尺寸只留一个主人。
- `rememberPressScale()`：主操作按下时轻微回弹。列表行仍交给系统水波，避免整屏都在动。

## 各场景的固定做法

| 状态变化 | 做法 |
| --- | --- |
| 页面进入 / 返回 | `AnimatedContent` + 整宽 6% 的视差位移，退出页反向 4.5%，两页不同步平移 |
| 启动页到首页 | 启动页叠在应用上淡出，同一块画面接力 |
| 卡片随状态换挡（学习卡、方向卡底部） | `contentSwap()`，用「状态」而不是文案做键，文案排版变化不会误触发 |
| 数值 / 短文案变化 | `ChangingText`，旧值淡出、新值从下方轻推入位，宽度跟着过渡 |
| 选项被选中、作答后收起 | 底色 `animateColorAsState` + `contentSwap()`，整组一起换 |
| 判分、错误、保存结果 | `appearFade()` / `disappearFade()`，高度交给外层卡片 |
| 展开区（先修课、图标、自定义课数、附件来源） | `expandFade()` / `shrinkFade()` |
| 全屏浮层（放大图示、重学遮罩） | 遮罩与卡片一起淡入缩放，关闭先收回再移除；窗口自带动画置 0，避免两层透明度叠加 |
| 进度条 | 任一卡片都由同一个 `SegmentedProgress` 补齐，首次出现直接显示现值 |
| 列表增删 | `Modifier.animateItem()`，聊天气泡只保留淡入淡出（尺寸动画会把阴影裁在边界内） |

## 约束

- **只用 alpha / transform**：新动效不改布局、不触发重新测量；换内容造成的尺寸变化由 `animateContentSize` 或 `SizeTransform` 单点承担，不叠加两层尺寸动画。
- **尊重系统设置**：所有 tween / spring 走 Compose 动画时钟，系统把「动画时长缩放」设为 0（移除动画）时直接落到终态。新增无限循环动画必须自行判断该设置；当前只有加载指示器是无限动画，且不承载信息。
- **跟手、可打断**：拖动（排序、滑块、拆信封）直接跟手，动画进行中再次操作从当前值接续，不重播。
- **无障碍**：换内容的地方不重复朗读，`liveRegion` 只放在最终会稳定下来的节点上；隐藏或退场的浮层移出可访问树。
- **测量方式**：长列表滚动用 `dumpsys gfxinfo <包名>` 对比改动前后（软件渲染的模拟器只能做相对比较，不作为绝对帧率结论）；Compose 交互改动须在真机或模拟器上验证触控语义、滑动、键盘避让与系统返回。
