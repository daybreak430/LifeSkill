# MVP 技术设计

## 架构与数据

单个 Android 应用模块使用 Kotlin、Compose、ViewModel 和 Room。页面通过 ViewModel 观察仓库。Room 统一保存三层项目、前置关系、对话与进度。父级外键级联清理子项目、关联边和所属对话。首次启动的种子记录与初始化标记同时写入，因此用户删除预置方向后不会被重新创建。

技能点可以依赖同树的多个节点，单个节点最多通往两个后续节点。手动保存与 AI 生成共用有向图与分叉校验。超额的旧依赖可原样保留或删除，新增连接仍受上限约束。

有效点亮按拓扑顺序计算。全部前置均有效点亮后才可进入教学对话，通过 AI 评估后点亮当前技能。锁定节点可查看详情，仓库在发送、重学和重试前校验解锁状态。保留旧版手动点亮记录。升级或修改前置关系后，前置未齐的旧点亮记录暂不计入进度，补齐前置后恢复。

技能地图按最长依赖路径分层，每层拆成每行最多两个节点，使用原生纵向列表滚动。短树的地图底板随节点内容收拢，较长的树在视口内滚动。技能名最多两行，行高随实际标签变化。跨行连线经过独立通道，每个节点最多绘制两条出线。可能交叉、超出通道容量或超过旧树分叉上限的关系用成对编号和关联列表呈现。

冷启动时系统启动窗口和 Compose 初始化页共用矢量标记与跟随系统外观的底色。技能库首次可用后立即进入相应页面，加载错误沿用重试入口。

数据库 v2 增加可空的图标、地图简称和选择题选项，Room 从 v1 自动迁移。没有存储图标的旧项目按层级使用默认图标，地图简称从完整名称派生。手动选择、AI 推荐和 AI 生成共用本地图标库。生成技能树和技能点时在同一次回复内选择图标，缺失、无效或默认图标由本地按内容补齐，写入时使用现有图标字段。

外观设置单独保存在本地，默认自动跟随系统。Compose 组件、画布、教学图表与系统栏使用同一主题选择。首页续学卡使用局部光晕和当前技能图标构成插图，窄屏和大字号时隐藏插图以留出阅读空间。方向卡用低饱和同色弧线和图标呈现已学会比例。方向、技能详情、设置和弹窗共用卡面、控件圆角与选中色。技能地图复用圆形徽章，已点亮徽章使用中绿渐变和白色图形。外环优先提示最近学习且仍可点亮的节点，否则提示地图顺序中的第一个可点亮节点。

AI 老师和 AI 生成共用青蓝对话样式，原生输入区支持多行、键盘避让和读屏。AI 入口的水晶图标与渐变使用原生 Compose 绘制，方向卡进度直接读取技能库。

首页通过 Room 查询用户在技能教学对话中发送的最后一条现存请求，定位最近学习的技能及所属树。若该技能锁定，首页入口打开技能详情。旧有教学记录可直接参与查询。生成对话及迟到的 AI 回复不会抢占续学入口。删除技能及其会话后，首页回退到上一条有效学习记录。首页与技能树列表采用原生 Compose 圆角矩形卡片、圆形徽章与分段进度条。

方向、技能树与技能点的新增和编辑共用表单弹窗。标题和保存栏固定，字段与展开的选项在表单区内滚动。

API Key、用户输入的技能名称和目标、对话正文均使用 Android Keystore AES-GCM 加密后保存。数据库仍保留索引所需的层级、关系、状态和标识。项目关闭系统备份及设备迁移的数据提取。

## AI 请求与本地状态

- 使用 OpenAI 兼容的 Chat Completions 接口进行非流式请求。DeepSeek 使用 JSON Output，MiniMax 和自定义接口通过提示词请求 JSON。模型思考内容不进入会话历史。网络层拒绝明文请求和重定向，避免把密钥发往另一个地址。
- 生成对话分为全局、方向和树三种作用域。全局和方向入口先预检新树，再将结果以加密草稿保存在对话里。新树的前置关系按同一棵树中的节点标识或唯一名称解析，无法定位的关系会略过并显示数量。旧草稿确认时也会按此规则解析。用户选已有方向或 AI 建议的新方向后，仓库在同一事务内校验并添加内容。树内追加节点仍严格校验对当前树的引用。App 拒绝截断、重复键和嵌套过深的响应。
- 每条待处理消息有稳定标识。回复为空、截断、未通过格式校验或生成数量越界时，App 按原请求补试一次并重新校验。重试沿用同一标识，完成的回复在事务中去重。失败保留输入，用户可重试或撤回编辑。若对话归属在请求期间被删，迟到的响应不再写入。
- 节点对话只发送当前学习目标及该节点近期消息。历史教学回复发给模型前编码为与当前回复协议一致的 JSON，界面继续渲染其中的 Markdown 正文。App 创建练习标识，只有当前练习有新回答、模型返回匹配的通过结果且写入时前置技能均已点亮，才会更新点亮状态。修改节点内容使旧练习失效。回答的质量和是否跑题由模型判断。
- 教学默认先讲解。AI 根据目标和进度通过 `offer_check` 邀请检验，邀请作为回复类型保存。技能已解锁时，最新回复为邀请即可检验。当前学习轮次和内容版本累计 5 条讲解回复后，用户可主动点「感觉已经会了，来考试吧」发起检验。仓库在写入请求前再次校验，开始考试只出题。继续学习和考试快捷回复都不参与练习判分。选择题选项和对话正文一同加密保存。Markdown 和表格由 CommonMark 解析，简易纵向 Mermaid 流程图使用原生 Compose 绘制，反馈箭头绕侧边返回，其他 Mermaid 语法显示源代码。
- 「重新学习」只在教学对话页提供。确认后在同一事务中删除当前会话的旧消息并写入新一轮请求，点亮进度保留。旧请求标识随记录删除，迟到的回复无法写入。新请求发送失败时可以重试，旧消息已清空。升级前留下的重学标记仍可用于划定模型上下文。
