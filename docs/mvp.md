# MVP 技术设计

## 架构与数据

单个 Android 应用模块使用 Kotlin、Compose、ViewModel 和 Room。页面通过 ViewModel 观察仓库。Room 统一保存三层项目、前置关系、对话与进度。父级外键级联清理子项目、关联边和所属对话。首次启动的种子记录与初始化标记同时写入，因此用户删除预置方向后不会被重新创建。

技能点可以依赖同树的多个节点，单个节点最多通往两个后续节点。手动保存与 AI 生成共用有向图与分叉校验。超额的旧依赖可原样保留或删除，新增连接仍受上限约束。

有效点亮按拓扑顺序计算。全部前置均有效点亮后才可进入教学对话，通过 AI 评估后点亮当前技能。锁定节点可查看详情，仓库在发送、重学和重试前校验解锁状态。保留旧版手动点亮记录。升级或修改前置关系后，前置未齐的旧点亮记录暂不计入进度，补齐前置后恢复。

逻辑层由最长前置路径决定，地图换行不改变层级。手动编辑和 AI 写入共用相邻层校验，阻止新增跨层前置或因编辑上游而产生的跨层关系。AI 新树在预检、显示及确认草稿时使用同一套前置关系整理规则。App 略过无法定位、自引用、成环、跨层或超出分叉上限的关系，保留所有课程，并在草稿及添加结果中显示略过的数量。地图仅绘制符合布局约束的相邻层连线，所有已保存的前置关系仍参与解锁，并可在技能详情查看。

AI 新树在整理前置关系后必须恰好有一个无前置的技能点。结合无环校验，其余技能点都能通过前置关系追溯到该起点。生成结果不符合条件时自动补试一次。确认添加时再次校验，包括从旧版保留的草稿。已添加的树和学习进度按原记录读取。

技能地图按最长依赖路径分层，每层拆成每行最多两个节点，使用原生纵向列表滚动。短树的地图底板随节点内容收拢，较长的树在视口内滚动。技能名最多两行，行高随实际标签变化。跨行连线经过独立通道，每个节点最多绘制两条出线。可能交叉、超出通道容量或超过旧树分叉上限的关系用成对编号和关联列表呈现。

考试通过消息与点亮进度同一事务提交。AI 老师随新通过消息显示深色徽章和 3 秒烟花，动画遵循系统动画设置，播完后保留遮罩和徽章，点击卡片下方的关闭按钮退出。旋转屏幕时恢复徽章，避免重播烟花。AI 老师页返回时直接进入该技能所在的地图。技能地图根据已提交的进度变化回放，进入地图 200 毫秒后点亮徽章，连线按路径填充，再打开并移除本次新解锁节点的锁。亮起和开锁各有一次遵循系统设置的轻触反馈，同时打开多个锁只触发一次。回放状态保存在当前运行的 ViewModel 内，避免重新打开应用时重复播放旧记录。

冷启动时系统启动窗口和 Compose 初始化页共用矢量标记与跟随系统外观的底色。技能库首次可用后立即进入相应页面，加载错误沿用重试入口。

桌面图标使用分层的 Android 自适应矢量资源。薄荷渐变铺满背景，进度弧和晶石位于前景安全区，最终外形交给桌面遮罩。

数据库 v2 增加可空的图标、地图简称和选择题选项，Room 从 v1 自动迁移。没有存储图标的旧项目按层级使用默认图标，地图简称从完整名称派生。手动选择、AI 推荐和 AI 生成共用本地图标库。生成技能树和技能点时在同一次回复内选择图标，缺失、无效或默认图标由本地按内容补齐，写入时使用现有图标字段。

外观设置单独保存在本地，默认自动跟随系统。Compose 组件、画布、教学图表与系统栏使用同一主题选择。首页主卡插图的光晕、外圈和节点按插图短边缩放，窄屏和大字号时用与标题同排的小插图。所有方向卡在同一字号下等高，创建技能树或添加技能点只更换卡内内容。方向、技能详情、设置和弹窗共用卡面、控件圆角与选中色。技能地图复用圆形徽章，已点亮徽章使用中绿渐变和白色图形。外环优先提示最近学习且仍可点亮的节点，否则提示地图顺序中的第一个可点亮节点。

AI 老师和 AI 生成共用青蓝对话样式，原生输入区支持多行、键盘避让和读屏。AI 入口的水晶图标与渐变使用原生 Compose 绘制，方向卡进度直接读取技能库。

首页通过 Room 查询用户在技能教学对话中发送的最后一条现存请求，定位最近学习的技能及所属树。没有记录时，主卡引导 AI 生成技能树。当前技能点亮后优先推荐可学的直接后续，再按技能顺序查找同树可学节点。整棵树已点亮时主卡打开地图，最近技能锁定时入口打开详情。旧有教学记录可直接参与查询。生成对话及迟到的 AI 回复不会抢占续学入口。删除技能及其会话后，首页回退到上一条有效学习记录。有技能点的方向卡展示数字和分段刻度，空方向提供快捷建树。方向卡刻度由上次显示的进度过渡至新值。

方向、技能树与技能点的新增和编辑共用表单弹窗。标题和保存栏固定，字段与展开的选项在表单区内滚动。手动保存只读取相关层级用于校验，列表刷新时复用密文未变化的解密结果。新条目提交后若在视口外，所在页面自动滚到该条目。

API Key、用户输入的技能名称和目标、对话正文均使用 Android Keystore AES-GCM 加密后保存。数据库仍保留索引所需的层级、关系、状态和标识。项目关闭系统备份及设备迁移的数据提取。

## AI 请求与本地状态

- 使用 OpenAI 兼容的 Chat Completions 接口进行非流式请求。DeepSeek 使用 JSON Output，MiniMax 和自定义接口通过提示词请求 JSON。DeepSeek 的 JSON Output 返回空正文时，会话补试停用服务端 JSON 模式，继续要求完整 JSON 并在本地校验。模型思考内容不进入会话历史。网络层拒绝明文请求和重定向，避免把密钥发往另一个地址。
- 生成对话分为全局、方向和树三种作用域。全局和方向入口先用 `offer_tree` 提议建树，App 弹窗让用户确认掌握程度和课程数量后再发起生成。掌握程度分初学者、进阶和专家，决定课程用语和目标深度。课程数量可选 3–5 节、8–12 节或自定义 1–33 节的整数。确认选项随待回复消息加密保存，重试沿用同一组选项。仓库在保存草稿前校验回复恰好包含一棵树且技能点数符合所选范围。首页仍可单独创建方向，树内追加仍严格校验对当前树的引用。
- 生成提示词引导 AI 将共享前置且可并行学习的技能放到同一层形成分支，并用真实的学习依赖决定路径。新树的前置关系按同一棵树中的节点标识或唯一名称解析，无法定位的关系会略过并显示数量。新草稿保存后自动打开方向弹窗。取消后可点草稿消息再次打开，旧草稿也通过消息进入确认。用户选已有方向或 AI 建议的新方向后，仓库在同一事务内校验并添加内容。App 拒绝截断、重复键和嵌套过深的响应。
- 添加结果在对话中显示新增数量及目标入口。历史消息按原有保存格式读取，前置关系提示在数量下方单独展示。新树规划只把本轮用户要求、连续的 `clarify_tree` 追问和本轮确认的提议发给模型。明确的新主题优先，只有主题无法确定或需要在多个新主题中取舍时才追问。规划阶段不发送现有方向列表，归属统一由生成草稿后的弹窗确认。旧提议、未添加草稿、添加回执和旧回复继续在本机对话中显示。树名是否重复由 App 在确认添加时查询所选方向的当前数据。
- 生成对话的更多菜单可在二次确认后清空当前作用域的消息和待添加草稿。清空使待回复请求失效，迟到的回复无法写回。已添加的项目、进度和其他会话继续保留。
- 每条待处理消息有稳定标识。回复为空、截断、未通过格式校验或生成数量越界时，App 按原请求补试一次并重新校验。重试沿用同一标识，完成的回复在事务中去重。失败保留输入，用户可重试或撤回编辑。若对话归属在请求期间被删，迟到的响应不再写入。
- 节点对话只发送当前学习目标及该节点近期消息。历史教学回复发给模型前编码为与当前回复协议一致的 JSON，界面继续渲染其中的 Markdown 正文。App 创建练习标识，只有当前练习有新回答、模型返回匹配的通过结果且写入时前置技能均已点亮，才会更新点亮状态。修改节点内容使旧练习失效。回答的质量和是否跑题由模型判断。
- 教学默认先讲解。AI 根据目标和进度通过 `offer_check` 邀请检验，邀请作为回复类型保存。技能已解锁时，最新回复为邀请即可检验。当前学习轮次和内容版本累计 5 条讲解回复后，用户可主动点「感觉已经会了，来考试吧」发起检验。仓库在写入请求前再次校验，开始考试只出题。继续学习和考试快捷回复都不参与练习判分。选择题选项和对话正文一同加密保存。Markdown 和表格由 CommonMark 解析。所有模型和历史消息共用本地流程图解析，识别常见节点、分支、链式箭头及回环，也接受省略图头的清晰流程。原生 Compose 统一纵向排版，其他 Mermaid 语法保留原文。
- 「重新学习」只在教学对话页提供。确认后在同一事务中删除当前会话的旧消息并写入新一轮请求，点亮进度保留。旧请求标识随记录删除，迟到的回复无法写入。新请求发送失败时可以重试，旧消息已清空。升级前留下的重学标记仍可用于划定模型上下文。
- 两种对话都支持 Unicode Box Drawing 与 ASCII 示意图，优先使用 `diagram` 代码围栏。字符图按等宽网格保留换行和缩进，宽字符按两列显示，过宽时可横向滑动。原生 Mermaid 流程图继续使用现有解析。

## 验收考试与挑战

- 有课程的技能树在地图末尾提供验收考试节点，全部课程有效点亮后解锁。验收和挑战不占生成课数，也不计入课程点亮进度。地图记录最高分，考试结果页显示本次分数。0、1–59、60–79、80–89、90–99 和 100 分使用六档徽章。
- 每次出题发送本树课程名、目标和当前版本的少量讲解摘录。四种题型各两题，单选、多选、填空每题 10 分，简答每题 20 分。AI 给逐题反馈和主观题得分，App 按题目答案核对选择题、校验得分范围并计算总分。未作答计 0 分。60 分通过，满分前可反复生成新卷。错题集保留历次未得满分的题目、作答、参考答案和反馈。
- 通过验收后显示两个挑战。「自以为是检测」每次只出一题，回答后直接反馈理解漏洞，三题都达标才成功。「费曼复习」逐轮指出术语、推理或过度简化的问题，直到解释准确且能让 10 岁孩子听懂。挑战成功后地图显示装饰徽章。
- Room v3 新增按树关联的试卷与挑战记录，v2 自动迁移。题目、答案、反馈及挑战对话加密保存，删除技能树时级联清理。出题、判卷和挑战的模型请求在事务外执行，提交时检查记录是否仍有效。结构校验失败时按原请求补试一次。
