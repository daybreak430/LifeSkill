# 交互教学与内置系列课

## 用户入口

从「新领域 → 交互教学体验」打开课程。首次安装和旧版本升级会补入四个分类会话：结构与过程、数据图表、互动练习、图像与综合。时间轴、流程图和三种对比配色归入「结构与过程」；需求预测、折线、柱状和面积图归入「数据图表」；答题、翻卡、排序、分类和分步推演归入「互动练习」；图片热点与数据观察、文字、对比、判断题的组合归入「图像与综合」。四个会话之间没有先修限制，每个会话已有标为「内置示例」的本地教学消息，无需 API Key 即可操作。

旧版本曾把每种示例拆成独立课时。升级时只合并未改名、未改写目标且没有追加对话的内置旧节点，并把已保存的互动状态迁移到对应分类会话；用户编辑过的名称或目标、包含个人追问的旧会话继续保留。若用户此前删除了「新领域」，首次补入时使用仍存在的第一个方向；没有方向时创建一个。

应用不会在普通启动或覆盖安装时自动复活整门演示课程。用户打开「新领域」后，缺失状态会显示一次「恢复演示课」操作；点击后只清除内置课程及其组件标记并重建四个分类会话。其他学习记录不受影响，重复点击也不会产生重复课程。

点击节点、切换维度、选择数据、调整价格、翻卡、移动排序、归类、点击热点和提交预测均由原生 Compose 执行。排序可长按拖动，也提供上下移动图形按钮；分类选项同时用颜色、勾选图标和读屏选中状态表达；图片热点支持单独查看。只有数据图表显示放大入口，其他组件不重复提供无必要的放大操作。图表放大后与主对话共享状态，系统返回先关闭图示。组件右侧重置只清除该组件的互动状态。状态在本机加密保存，重开课时后保留。

放大视图使用带外部遮罩的近全屏大圆角卡片，保留系统安全区，不占满整个屏幕。知识翻卡只由卡内“翻面／翻回”按钮驱动，使用 520 ms 的 Y 轴三维翻转；拖放排序使用 Apache-2.0 的 Calvin-LL Reorderable 3.1.0，按住拖动点后直接移动并让其他条目平滑让位，同时保留上下移动按钮供无障碍操作。

内置示例是预置教案，不是实时模型回复。继续追问仍需要配置模型，必要的组件内容和互动摘要会随近期对话发送给所选服务。AI 可自行组合文字与组件，用户也可要求「用时间轴讲」「用对比卡说明」等。仅提供 JSON 数据的自定义模型同样可以使用；组件数据不合法时保留独立可读的文字讲解。

## 协议与边界

`AiProtocol.tutor` 在原有 `reply`、`kind` 之外接受可选 `blocks`。当前支持 `text`、`timeline`、`flow`、`compare`、`chart`、`quiz`、`flip`、`sort`、`classify`、`hotspot`、`steps`。`reply` 始终必填，既是概括也是组件降级时的阅读内容。实时模型提示词要求最多3个组件；持久化解码器允许一个内置分类会话最多16个组件，防止后续同类示例增加时再次拆节点。组件 ID 在一条消息内唯一，状态以消息 ID＋组件 ID 定位。

模型先生成课程时，会按主题设计不同的认知动作，目标避免只写“了解、熟悉、掌握”，而会明确比较、读图、排序、分类、回忆或推演等可检验结果。具体教学回复再根据本节目标选择组件：时序用时间轴，分支流程用流程图，易混概念用对比，定量变化用图表，记忆条件用翻卡，连续顺序用排序，类别判断用分类，计算与因果链用分步推演；植物细胞热点只用于对应知识。没有匹配意图时只输出文字，通常使用0–2个组件，避免把同一信息重复包装成组件。

对 DeepSeek Flash 的历史、数据分析、操作流程、语言和植物细胞五个主题实测及误用修正见[组件主题选择实测](component-selection-audit-2026-11-21.md)。

`TeachingBlockProtocol` 限制总长度、数组数量、文本长度、有限数值、引用和题目选项。流程复用 `LessonFlow` 解析、原生排版和回环处理。排序必须给出不重复且完整覆盖所有条目的正确顺序；分类条目必须引用已声明类别；分步推演必须为每步提供一处预测检查点。热点只接受应用内置的 `plant_cell` 图像模板和 0–100 百分比坐标，不接受模型图片 URL。未知类型或无效组件逐个丢弃，不能执行代码、打开资源或发起业务操作。数据库中保存生成时的组件快照，更新教案不会改变旧消息的题目和判定依据。

`chart/data` 支持2–12个数据点，标注横纵轴和单位，可点选曲线节点或下面的数据项。`chart/linear_demand` 是应用实现的固定模板 `Q = 120 − 10P`，P为2–10元，可带预测题；数量单位由可选 `quantityUnit` 明确（如杯、件、张），缺省显示「单位」。固定模板的横轴始终为需求量、纵轴始终为价格，避免模型把坐标标反。滑动过程中只更新页面数值，松手才写入状态。该模板仅用于其他条件不变的需求教学，不是任意公式引擎或现实销量预测。

随堂题、排序、分类和分步推演统一采用“先提示、允许重试、由学生主动查看完整答案”的反馈。错误提交只显示不解题的线索；更改答案、顺序或分类后可再次提交；只有点击“查看完整答案”才显示解释或正确方案。重复提交不增加次数；随堂题答对后锁定，分步推演答对后仍可改选并重新验证，重置后可重新体验。分步推演进入下一步时会把新的当前步骤滚入视口。它们不调用 `lightFromAssessment`，不占正式题号，也不修改课时完成或发证资格。正式课后练习继续走原有 `kind/question/choices/exerciseId` 状态机；待答正式题期间不接受新教学组件。

`TeachingInteractions` 是纯领域状态转换器。UI 只转发动作；`ChatViewModel` 串行提交互动并在发出追问前等待已提交动作；`ConversationRepository` 在事务中重新读取消息、校验归属、版本、解锁状态和组件引用，再加密写回。消息或课时删除后，迟到的动作不能重建内容。

Room v13 给 `turns` 增加可空的 `teachingBlocks`、`teachingStates`，分别按消息 ID 绑定 Android Keystore 加密。v12→v13自动迁移，旧消息读取为空组件。导出的 Markdown 保留图示内容、数据与互动摘要；未作答的题不主动导出答案。模型上下文超过组件预算时使用有界摘要，避免大组件把整条近期消息挤出上下文。

## 增加一种交互时按类别收纳

1. 在 `model/TeachingBlocks.kt` 增加类型及必要的纯状态转换。计算模板需要明确输入边界、单位、假设和验证用例。
2. 在 `ai/TeachingBlockProtocol.kt` 增加编解码、数据约束、模型提示词；保持未知类型降级和文字兼容。按需要更新模型历史摘要与 Markdown 导出。
3. 在 `ui/TeachingContent.kt` 注册原生渲染器；复杂组件可放入独立 UI 文件。复用现有颜色、控件和弹层，确保触控目标、读屏名称、滚动及系统返回可用。图形按钮必须使用固定版本 Lucide 资源。
4. 在 `model/BuiltInTeaching.kt` 选择「structure、data、practice、visual」中的一个分类会话，向 `items` **追加一个带独立安装标记的组件**。现有分类课时标记为2001–2004，组件标记1001–1020已经使用，后续从1021继续分配。只有确实引入不属于这四个类别的新交互时，才新增分类会话和新的稳定 `key`、标记。
5. `LibraryRepository.initialize` 会在保留的分类会话中追加缺少的组件；若会话存在但示例消息被清空，只创建一个包含新组件的内置消息，不重建已删除的旧组件。不会覆盖用户对课时的编辑，也不会自动重建用户删除的课或课时。用户删除整门课后，只有从「新领域」主动选择「恢复演示课」才会执行事务化恢复。
6. 补领域、协议、存储和迁移测试，并在模拟器验证触控边界、横纵滑动、键盘与系统返回。每种新增类型都应在同一课程中有可离线体验的验收样例。

## 本次验证范围

领域单测、旧协议及仓库回归通过；`TeachingStorageTest` 覆盖四个分类会话安装、旧课时合并、分类内追加组件、删除不复活、加密状态与重开、随堂正确不点亮、模型格式降级和真实v12数据库迁移。`TeachingUiTest` 在 Android 16 模拟器验证原生交互、实际触控滑块、翻面按钮、按住拖放排序、排序上下移动、分类重试、热点、分步推演连续推进与答对后改选、流程横滑与纵滑、键盘、图示与系统返回。真机和其他 Android 版本未在本次自动验收中覆盖。

组件选项的最小触控高度由居中容器承担，文本按自身行高测量；同组对比卡使用内容决定的统一高度。放大和重置使用带可访问名称的Lucide图形按钮。全应用公共功能图标和附件图标复用固定版本的Lucide矢量资源，品牌插画、图表和证书装饰不作为功能图标处理。

## 配色与图表样式

对比卡可选 palette：blue_amber（默认蓝金）、violet_teal（紫青）、rose_sage（玫瑰绿）。色彩区分对象，同时保留文本标题，深色主题自动调整明度；同组继续等高、顶部对齐。

数据图可选 style：line（默认折线）、bar（柱状）、area（面积）。样式不改变原始数值、单位与点选状态；柱状图围绕零基线绘制，面积图闭合到零基线，不自动累计数据。需求模板始终使用折线。旧消息缺少可选字段时沿用默认样式，未知字段值降级到默认，无需数据库迁移。

时间轴采用贯穿各行的连续线与选中节点光环，展开详情不会打断轴线。三种对比配色共用「结构与过程」，三种图表样式共用「数据图表」。旧版独立示例升级后不再作为新节点重复出现；用户编辑过的旧节点和包含个人追问的会话保持原样。
