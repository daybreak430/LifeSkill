# 交互教学与内置系列课

## 用户入口

从「新领域 → 交互教学体验」打开课程。首次安装和旧版本升级都会补入六节课：时间轴、流程图、对比卡、交互图表、随堂答题、混合讲解。课时之间没有先修限制。每节已有标为「内置示例」的本地教学消息，无需 API Key 即可操作。若用户此前删除了「新领域」，首次补入时使用仍存在的第一个方向；没有方向时创建一个。

点击节点、切换维度、选择数据、调整价格、提交随堂答案和放大均由原生 Compose 执行。图示放大后与主对话共享状态，系统返回先关闭图示。组件右侧重置只清除该组件的互动状态。状态在本机加密保存，重开课时后保留。

内置示例是预置教案，不是实时模型回复。继续追问仍需要配置模型，必要的组件内容和互动摘要会随近期对话发送给所选服务。AI 可自行组合文字与组件，用户也可要求「用时间轴讲」「用对比卡说明」等。仅提供 JSON 数据的自定义模型同样可以使用；组件数据不合法时保留独立可读的文字讲解。

## 协议与边界

`AiProtocol.tutor` 在原有 `reply`、`kind` 之外接受可选 `blocks`。当前为第一版数据协议，支持 `text`、`timeline`、`flow`、`compare`、`chart`、`quiz`。`reply` 始终必填，既是概括也是组件降级时的阅读内容。每条最多接受4个组件，提示词通常要求最多3个。组件 ID 在一条消息内唯一，状态以消息 ID＋组件 ID 定位。

`TeachingBlockProtocol` 限制总长度、数组数量、文本长度、有限数值、引用和题目选项。流程复用 `LessonFlow` 解析、原生排版和回环处理。未知类型或无效组件逐个丢弃，不能执行代码、打开资源或发起业务操作。数据库中保存生成时的组件快照，更新教案不会改变旧消息的题目和判定依据。

`chart/data` 支持2–12个数据点，标注横纵轴和单位，可点选曲线节点或下面的数据项。`chart/linear_demand` 是应用实现的固定模板 `Q = 120 − 10P`，P为2–10元，可带预测题；数量单位由可选 `quantityUnit` 明确（如杯、件、张），缺省显示「单位」。固定模板的横轴始终为需求量、纵轴始终为价格，避免模型把坐标标反。滑动过程中只更新页面数值，松手才写入状态。该模板仅用于其他条件不变的需求教学，不是任意公式引擎或现实销量预测。

随堂题由题目快照中的选项和答案提供本地反馈，错误可重答，重复提交不增加次数，答对后不能继续改选，重置后可重新体验。它不调用 `lightFromAssessment`，不占正式题号，也不修改课时完成或发证资格。正式课后练习继续走原有 `kind/question/choices/exerciseId` 状态机；待答正式题期间不接受新教学组件。

`TeachingInteractions` 是纯领域状态转换器。UI 只转发动作；`ChatViewModel` 串行提交互动并在发出追问前等待已提交动作；`ConversationRepository` 在事务中重新读取消息、校验归属、版本、解锁状态和组件引用，再加密写回。消息或课时删除后，迟到的动作不能重建内容。

Room v13 给 `turns` 增加可空的 `teachingBlocks`、`teachingStates`，分别按消息 ID 绑定 Android Keystore 加密。v12→v13自动迁移，旧消息读取为空组件。导出的 Markdown 保留图示内容、数据与互动摘要；未作答的题不主动导出答案。模型上下文超过组件预算时使用有界摘要，避免大组件把整条近期消息挤出上下文。

## 增加一种交互时必须更新同一门课

1. 在 `model/TeachingBlocks.kt` 增加类型及必要的纯状态转换。计算模板需要明确输入边界、单位、假设和验证用例。
2. 在 `ai/TeachingBlockProtocol.kt` 增加编解码、数据约束、模型提示词；保持未知类型降级和文字兼容。按需要更新模型历史摘要与 Markdown 导出。
3. 在 `ui/TeachingContent.kt` 注册原生渲染器。复用现有颜色、控件和弹层，确保触控目标、读屏名称、滚动及系统返回可用。
4. 在 `model/BuiltInTeaching.kt` 的 `lessons` **追加一节专门展示新类型的课**，使用新的稳定 `key` 与新的 `installMarker`。现有标记1000用于课程，1001–1006用于首批课时，后续从1007继续分配。不得按列表下标动态分配，也不得复用旧ID或标记。
5. `LibraryRepository.initialize` 会为保留这门课的既有用户补入新课时，创建教案快照；不会覆盖用户修改，也不会重建用户删除的课或课时。用户删除整门课后，不再自动补入后续类型。
6. 补领域、协议、存储和迁移测试，并在模拟器验证触控边界、横纵滑动、键盘与系统返回。每种新增类型都应在同一课程中有可离线体验的验收样例。

## 本次验证范围

首轮领域单测、旧协议及仓库回归通过；`TeachingStorageTest` 覆盖六课安装、模拟追加新课、删除不复活、加密状态与重开、随堂正确不点亮、模型格式降级和真实v12数据库迁移。`TeachingUiTest` 在Android 16模拟器验证原生交互、实际触控滑块、流程横滑与纵滑、键盘、图示与系统返回。真机和其他Android版本未在本次自动验收中覆盖。

组件选项的最小触控高度由居中容器承担，文本按自身行高测量；同组对比卡使用内容决定的统一高度。放大和重置使用带可访问名称的Lucide图形按钮。全应用公共功能图标和附件图标复用固定版本的Lucide矢量资源，品牌插画、图表和证书装饰不作为功能图标处理。
