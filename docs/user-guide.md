# LifeSkill 使用指南

1. 按 [README 的安装说明](../README.md#安装) 获取安装包。支持 Android 8.0（API 26）及以上。已安装后，在「我的 → 设置 → 关于 LifeSkill」查看当前版本，点「查看发布版本」打开 GitHub Releases 列表，选择版本下载 APK 并手动覆盖安装。
2. 首页主卡可开始规划或继续学习。完成本节后，首页推荐同一门课程里可学习的下一节。学完全部课时后可从首页查看课程。方向卡显示已完成课时和总课时，空方向可直接新建课程。在方向页右上角「⋯ → 编辑方向 → 图标颜色」可为图标和方向进度条选色。领取结业证书后，学习方向中的课程卡显示「已领证书」。课程大纲可纵向滚动，并标记已完成、可学习和需先修的课时。
3. 从悬浮底栏切换「学习」和「我的」。「我的」可查看学习总览、浏览全部证书缩略图，并选择 12 款插画头像或相册照片。右上角「设置」可选浅色、深色或自动跟随系统。使用 AI 前，在「模型设置」选择 DeepSeek 或 MiniMax 并填入对应的 API Key。选择 DeepSeek 并填写 API Key 后，可在模型设置底部查询或刷新「账户余额」。也可选「自定义」，填写 OpenAI 兼容服务的 HTTPS Base URL、模型名和 Key。「测试连接」验证当前表单，「保存」将其设为当前模型。
4. 在首页或方向页的 AI 对话中描述学习目标。主题明确时会直接弹出生成选项。选择你的基础和课时数量，再点「确认生成」。每次生成一门课程，最多 33 节。课程从一节起始课开始，其余课时按先修关系安排。草稿生成后会自动弹出「选择学习方向」，选好方向后点「添加课程」。取消后可点草稿消息重新选择。在课程内选择「AI 补充课时」，可为这门课程添加新的课时。结果消息可跳转到对应项目。右上角更多菜单可以清空当前会话，二次确认后会删除聊天记录和未添加的草稿，保留已添加的内容。
5. 点课时查看完整名称、学习目标和先修课。编辑时可选择上一学习阶段的课时作为先修课。完成先修课后可开始学习，通过 AI 老师给出的课后练习后，本节标记为已完成。
6. 讲解时，可点回复下方的「好的，继续」接着学。本轮讲解满 5 次后，可主动点「做课后练习」。AI 老师也可以提前邀请你做练习。每次出一题，答对两题后，AI 老师根据作答情况决定是否加一道题。选择题直接点选项作答，答错后可在提示下重答当前题。开放题可点「重新出本题」，保留此前的作答进度。讲解支持 Markdown、表格和原生排版的流程图，结构示意图可横向滑动。AI 对话收到回复时会保留当前阅读位置，可手动向下滑动查看。
7. 在 AI 老师页右上角「⋯」中选择「重新学习」。确认后会清空本节的旧学习对话，保留完成进度。可填写本次要求，AI 会按本节的学习目标重新讲解。AI 老师页和课程大纲右上角的「⋯ → 导出对话」会打开系统分享面板，将仍保存在本机的学习对话作为 Markdown 文件分享。整门课程导出按课时名称分节。
8. 完成一门课程的全部课时后，从课程大纲末尾进入「结业考试」。AI 根据已学课时出 10 道题，包含 4 道单选、3 道多选和 3 道填空。交卷后显示本次分数，可查看历次错题。60 分通过，最高分显示在课程大纲，达到 100 分前可以重考。通过后可上滑拆开信封，证书保存当时的昵称、头像和领取日期。同一门课程只签发一张。可从成绩页或「我的」我的证书查看，删除课程也会保留已领取的证书。在展柜打开证书后可隐藏它，之后从「已隐藏」恢复展示。大图页的「更多」菜单可隐藏或永久删除证书。删除后将从「我的证书」和已领取证书统计中移除。示例证书也可隐藏或删除，已领取证书统计只计入正式证书。
9. 通过结业考试后，课程大纲末尾会显示两项课后复习。「查漏补缺」用三道题找出理解漏洞，「费曼复述」请你用自己的话，把概念讲给 10 岁的孩子听。

## 对话附件

在「AI 生成课程」或「AI 老师」的发送按钮左侧点「＋」，可拍照、从相册选择图片，或选择 PDF、DOCX、TXT、Markdown 文件。每条消息最多 3 个附件，单个不超过 8 MB。图片显示缩略图，PDF、Word、TXT 和 Markdown 各有对应图标。发送前点缩略图或文件卡片可预览，点卡片右上角的叉可移除。只发附件也可以。发送后附件显示在对话右侧，并加密保留在本机，可从历史消息中预览或保存原件。清空当前会话或重新学习会删除对应的附件。

应用在点发送后才把图片或提取的正文交给当前模型。发送图片需使用内置的 DeepSeek Flash 或 MiniMax M3.1 Flash，由模型直接识图。PDF 读取前 50 页内可提取的文字。扫描 PDF 可将需要的页保存为图片后发送。导出的 Markdown 会列出附件名称。

用附件生成新课程时，AI 默认按原文的主要章节和实际用途规划。课时较少时会合并相近章节。生成阶段会复用本轮近期上传的资料，每次最多发送 6 个附件、48,000 字符正文。超出范围或无法读清的内容可分批补充。添加课程后，每节课保留与其相关的资料要点，供讲解、复习和课后练习使用。普通对话单次最多发送 24,000 字符附件正文。

## 联网搜索

使用官方 DeepSeek Flash 或 MiniMax M3.1 Flash 时，可在 AI 对话输入框下方打开「深度思考」。开关默认关闭，开启后本对话的后续请求使用更高的思考强度。DeepSeek 关闭时使用非思考模式，MiniMax 关闭时使用低强度。可以同时开启「联网搜索」；回复显示最终讲解，等待时间和 Token 用量可能增加。

使用 DeepSeek 官方模型时，AI 对话输入框下方的「联网搜索」默认开启，可随时关闭。开启时，发送问题、开始学习、继续讲解和重新学习都会搜索。回复开头点「查看来源」可打开链接列表。搜索没有可用来源时会显示提示。课后练习作答不搜索。

在「AI 老师」用 DeepSeek Flash 并开启联网搜索时，可以接着上文说「给个案例看看」或「给我看一张参考图」。AI 会在适合用图讲解的主题中查找维基共享资源的图片，挑一张放进同一条回复，并结合画面讲解。点图可放大，图下可查看来源和许可。没有找到合适的图时会给文字案例。看图请求的 Token 计入本节用量。

## AI 用量

在课程详情、课时详情或 AI 老师对话中，点右上角「⋯ → AI 用量」查看 Token 和预估费用。课时详情和 AI 老师对话共用本节讲解、问答和练习的累计用量，课程详情汇总各课时、已添加的课程生成、补充课时、结业考试和考后复习。证书大图下方显示该课程的累计值。「我的」学习统计还会计入无法归属到课程的请求，例如课程规划对话和测试连接。

预估费用合计模型 Token 费用和联网搜索费用。模型费用按 DeepSeek 和 MiniMax 官方接口回执、缓存和输入输出单价以人民币估算，包括自动重试中带回执的请求。网页搜索每次成功且返回结果收取 ¥0.005，搜索费用按次计入课时、课程和全局用量。课时和课程的用量面板会显示计费搜索次数及其金额。DeepSeek 的时段费率包含已配置的 2026 年节假日，后续年份按常规周一至周五时段估算。MiniMax 订阅请求和缺少计费数据的请求仍计入 Token，相关费用不计入预估。账单以服务商为准，未记录回执的历史用量无法补算。[DeepSeek 计费规则](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/) · [DeepSeek 网页搜索计费](https://api-docs.deepseek.com/zh-cn/guides/search/#计费) · [MiniMax 计费规则](https://platform.minimax.cn/docs/pricing/overview#llm)

课程、学习进度、聊天记录、用量、个人资料和证书保存在应用本地。清空对话或删除课程后，已记录的支出仍计入总用量。AI 对话将当前任务所需的内容发送给所选模型服务，使用该服务商账户的额度。卸载或清除应用数据会删除本地记录。
